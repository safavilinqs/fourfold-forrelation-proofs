# Verification code

The paper package preserves the complete Round-2 and Round-3 history and an audited Round-4 tree under `source_snapshot/` because the accepted Round-4 suite imports functions and regressions from its two predecessor folders by relative path. The audit corrected the theorem scope to fresh probes block diagonal in total signal photon number.

Run the theorem-critical checks and the manuscript contract with:

```bash
./run_all.sh
```

Run the complete inherited suite with:

```bash
./run_all.sh --full
```

The wrapper uses `PYTHON_BIN` when that environment variable is set; otherwise it selects the first local Python interpreter with NumPy from the original Miniconda path, the Homebrew Python 3.13 path, and the current `PATH`. The focused command checks the conventional bibliography citations, scope language, committed vector-figure contract, exact 888-entry balanced theorem map, rejection of every unbalanced routing placeholder, the 272-incidence/136-edge scope witness, and the theorem artifacts used directly in the manuscript. The full command reuses the same interpreter and may require NumPy, SciPy, and SymPy. Historical tests remain useful regression evidence but do not enlarge the corrected theorem scope.
