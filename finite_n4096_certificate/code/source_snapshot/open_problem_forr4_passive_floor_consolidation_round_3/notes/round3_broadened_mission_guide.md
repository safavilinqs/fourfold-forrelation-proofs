# Round 3 broadened mission guide

Date: 2026-07-15

For the short nontechnical charter, start with `../ROUND_3_CHARTER.md`.  This
note applies that charter to the current technical frontier.

## The plain-language program

The program asks whether active sensing can solve four-forrelation with
substantially less physical exposure than passive sensing, how large that
advantage is, and why it exists.

The earlier rounds answered the first question: a real asymptotic gap is
proved.  Passive hard dose must grow at least as
\(\Omega(N^{1/24})\), while an active construction uses at most six.  Round 3
should determine whether that theorem is practically visible, whether its
passive exponent can be strengthened, and whether six is the true active
benchmark.

Round 3 has now strengthened the passive floor to \(\Omega(N^{1/12})\) and
closed the complete finite terminal obstruction list.  The bare scale at
\(N=1024\) is still only about \(1.782\), so the realistic-size,
passive-protocol, alternative-witness, and active-boundary questions remain
open.

## What Round 3 must not collapse into

The current signed-permutation ledger is one route to a finite-size theorem.
It is not the overall mission.  Likewise, improving the reverse-tree
exponent is one route to stronger general theory, and searching for a
dose-five active protocol is one boundary test.  None should monopolize the
round merely because it has the most developed notation.

The three tracks answer different parts of one question:

| track | plain-language question | current bounded project |
|---|---|---|
| A | Can we see the active advantage around \(N=1024\)? | control the 888 balanced high-sector entries that reach the dose-six ledger, then complete the one-batch and adaptive gates |
| B | Can we prove that the passive disadvantage grows faster in general? | the generic level-twelve graph norm is now sharp; test physical frame restrictions, explicit constants, or a replacement witness while retaining the \(N^{1/12}\) theorem |
| C | Are we comparing against the right algorithms and hard examples? | test one coherent extra query or a genuinely interleaved five-traversal active circuit; screen a passive protocol and a named replacement under common gates |

The comparison is four-sided, not just “passive lower versus active six.”
`../BOUNDARY_MAP.md` separately tracks passive lower evidence, passive
protocol evidence, active lower evidence, and active protocols.  The passive
protocol cell is currently the least developed and is therefore an explicit
Round 3 deliverable rather than an assumed background fact.

## The integrated end product

Round 3 should end with one short answer containing five pieces:

1. the strongest rigorous asymptotic theorem;
2. a yes/no verdict at the \(N=1024,D=6\) benchmark;
3. the best known upper and lower evidence on both passive and active dose;
4. the mathematical mechanism that is actually proved, with adaptive scope
   stated honestly; and
5. a decision about which hard instance and contraction framework should be
   continued.

This allows several legitimate strong outcomes.  A finite-size separation,
a better exponent, a dose-five protocol, or a rigorous obstruction that
forces a better hard instance can all materially advance the original
program.  Local algebra without one of these consequences remains a
diagnostic.
