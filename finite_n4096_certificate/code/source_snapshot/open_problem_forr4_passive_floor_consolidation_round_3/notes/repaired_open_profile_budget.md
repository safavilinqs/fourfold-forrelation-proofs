For (3.1), put both endpoint pairs on nonzero vertical differences and put
the quintic triple in one hidden column.  The row Gram has exact reductions
by endpoint xor, two hidden-column Fourier classes, and a twisted common-row
translation.  Each final positive-semidefinite block has size

$$
q(q-1)^2.
$$

The resulting exact symmetry reduction, evaluated numerically at finite
\(q\), gives:

| \(q\) | \(N=q^2\) | coefficient |
|---:|---:|---:|
| 4 | 16 | \(0.0554262492783\) |
| 8 | 64 | \(0.0825349366921\) |
| 16 | 256 | \(0.0401545711400\) |
| 32 | 1024 | \(\ge0.0142810242047\), certified from one Fourier class |

The \(q=4\) value agrees with a direct physical matrix construction.  The

the dominant class.  This gives a physical coefficient above (3.2).  See
`transposed_dominant_class_and_hybrid_repair.md`.

The result is a lower witness on the arbitrary-law coefficient, not an upper
contraction theorem.
