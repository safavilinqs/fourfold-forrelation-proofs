# Round 4 searches

Searches must answer a bounded question from OPEN_PROBLEMS.md.

Every search should state:

- exact model and candidate;
- theorem, protocol, or falsification gate;
- dimensions and dose;
- exact versus floating-point operations;
- output artifact;
- stop rule; and
- whether the result is diagnostic or certified.

The first search reconstructs the full one-batch dose-six ledger, groups the
848 unresolved balanced entries, and audits the supported finite-size
geometry. The new lead search must evaluate one compatible physical law
across the 16- and 51-orbit impact frontiers. A search that optimizes only one
more orbit does not satisfy the Round 4 decision target.

Implemented:

- `finite_size_passive_ledger.py` generates the 888-entry balanced ledger,
  224 unresolved orbit rows, corrected Round 3 provenance, the impact
  frontier, current gates, and finite-size implementation window.
- `opposite_endpoint_correlated_mixture.py` optimizes the valid
  full-row-symmetry-invariant physical lower-witness family. It explicitly
  forbids applying the fourteen-class reduction to nonsymmetric laws.
- `opposite_endpoint_two_axis_mixture.py` evaluates the first valid
  non-invariant extension suggested by the order-four optimizer. Its
  25-block reduction is checked against the unreduced order-four formula;
  the order-32 result closes this local screen below the kill gate.
- `signed_permutation_link_moment.py` evaluates sparse Fourier moments of one
  plant link exactly at arbitrary power-of-two order without enumerating
  signed permutations.
- `joint_impact_sparse_q4.py` builds one common configuration-level law for
  the leading 16 unresolved families, searches a small order-four baseline,
  and reevaluates the selected law in an order-32 embedding. Its output is a
  joint-law and cancellation diagnostic, not a finite-size passive theorem.
- `quadratic_bent_replacement_screen.py` evaluates the exact-promise
  replacement in the same dose-six occupation architecture. It computes the
  complete compatible inventory and hypothetical common-coefficient gates;
  it does not claim those coefficients have been proved for the plant.
- `q64_adaptive_tree_frontier.py` records the exact multiplier-one consequence of the adaptive direct-sum factorization against the committed outward ledger. The proof is analytic; the script protects the resulting total, reserve, scope, and artifact.
