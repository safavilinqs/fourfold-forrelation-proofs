# Figures

The paper figures are generated by `generate_figures.py` from exact formulas and the audited Round-4 balanced-ledger artifact. The phase masks are always displayed as two-dimensional coordinate grids because the theorem uses the factorization $4096=64^2$; the square indexing is a mathematical representation and does not assert a square physical device.

Generate all committed PDF and SVG outputs with:

```bash
/opt/homebrew/Caskroom/miniconda/base/bin/python3 generate_figures.py
```

Check the exact plant identity, ledger count, and committed vector outputs without rewriting them with:

```bash
/opt/homebrew/Caskroom/miniconda/base/bin/python3 generate_figures.py --check
```

The deterministic signed-permutation example uses NumPy generator seed `4096`. The script verifies the unattenuated $q=64$ plant by an integer fast Walsh--Hadamard contraction and requires the exact ratio to equal one before writing the phase-grid figure.
